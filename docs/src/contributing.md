# Contributing

See [CONTRIBUTING.md](https://github.com/SorobanLabs/sorobanlabs-analyzer/blob/main/CONTRIBUTING.md)
in the repository root for the full, current contribution guide:
prerequisites, development setup, required checks, coding guidelines,
and scope (what kinds of contributions are and are not in scope for this
project — see its "Scope" section before proposing new functionality).

Discussion and contribution happen through GitHub
[issues](https://github.com/SorobanLabs/sorobanlabs-analyzer/issues)
and pull requests on this repository; there is no separate community
channel.
